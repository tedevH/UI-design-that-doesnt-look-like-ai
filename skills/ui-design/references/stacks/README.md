# Stack guide index

Use a guide only after identifying the project's actual framework and conventions. These notes keep the art direction intact while changing implementation and review details for the platform. They are not starter templates and do not override the project's current design system.

| Planner ID | Guide | Focus |
| --- | --- | --- |
| `web-native` | [Native HTML, CSS, and JavaScript](web-native.md) | Browser semantics and small standalone pages |
| `react` | [React](react.md) | Component, state, and interaction boundaries |
| `nextjs` | [Next.js](nextjs.md) | Routing and server/client boundaries |
| `vue` | [Vue](vue.md) | Component data flow and reactive state |
| `sveltekit` | [SvelteKit](sveltekit.md) | Route data and form actions |
| `tailwind` | [Tailwind CSS](tailwind.md) | Theme tokens and utility composition |
| `swiftui` | [SwiftUI](swiftui.md) | Native iOS views, Dynamic Type, and safe areas |
| `compose` | [Jetpack Compose](compose.md) | State hoisting, density, semantics, and insets |
| `react-native` | [React Native](react-native.md) | Cross-platform controls and device behavior |
| `flutter` | [Flutter](flutter.md) | Widget composition, themes, and platform layouts |

For each platform, inspect the repository first, use its existing libraries, and preview on the actual target device or route. Do not add a framework or replace a working design system merely to follow a guide.
